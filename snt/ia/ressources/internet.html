Comment deux machines
se parlent

La séance dernière, nous cherchions les documents à sa place. Pour qu'un assistant aille les chercher lui-même, il doit savoir frapper à la porte d'autres machines. Ces portes ont un nom : les API. Et avant d'y arriver, il faut remettre deux mots à leur place : Internet et le Web.

Internet · Web · URL · API · JSON · où tourne le modèle
Deux mots qu'on confond tous les jours

Internet n'est
pas le Web

On les emploie l'un pour l'autre, et c'est une erreur utile à corriger : tout le reste de la séance en dépend. L'un est un réseau, l'autre est un service qui circule dessus. Comme la route et l’autocar.

Internet

l'infrastructure · 1969 →

Des câbles, des antennes, des routeurs, et une convention pour découper les messages en paquets et les adresser. Internet ne sait pas ce qu'il transporte : il transporte.

adresses IP · paquets · routage

Le Web

un service parmi d'autres · 1991 →

Un système de pages liées entre elles, inventé trente ans plus tard, qui voyage dans les tuyaux d'Internet. Des adresses (URL), un langage de page (HTML), une façon de demander (HTTP).

URL · HTTP · HTML · liens

Dans les mêmes tuyaux circulent aussi le courrier électronique, la visioconférence, les jeux en ligne, les applications de votre téléphone — et les API, dans un instant. Aucun de ces services n'est « le Web ». Dire « je vais sur Internet » quand on ouvre un navigateur, c'est dire « je vais sur la route » quand on prend le bus.

Manipulation ③ · la même information, deux publics

Qu'est-ce
qu'une API ?

Un même serveur peut répondre de deux façons : une page, faite pour des yeux, ou des données nues, faites pour un programme. La seconde porte, c'est une API — application programming interface, l'interface par laquelle un programme s'adresse à un autre.

Pour un humain

Pour un programme

Même donnée, deux emballages. La page porte un menu, une publicité, une mise en page qui changera l'an prochain ; le JSON ne porte que l'information, et garde la même forme — c'est un contrat. Un programme peut s'y fier ; sur une page, il devrait deviner une mise en page.

Manipulation ④ · l'API d'un modèle, et sa mémoire de poisson

Appeler un modèle

Un modèle de langage s'appelle exactement comme la météo : on envoie du JSON, on reçoit du JSON. Avec une surprise : l'API ne garde rien entre deux appels. Cliquez pour poursuivre la conversation et regardez ce qui part sur le réseau.

Pas de mémoire

le modèle est sans état

À chaque appel, le programme renvoie tout l'historique. Le modèle relit la conversation entière comme s'il la découvrait, puis prédit la suite — et oublie aussitôt.

Ce qu'un chat appelle « mémoire » est donc une fonction de l'application, pas du modèle. On y revient à la séance suivante.

Manipulation ⑤ · la question la plus concrète de la séance

Où est le modèle ?

On peut interroger la même IA de trois façons, et ce n'est pas un détail de confort : à chaque fois, votre texte ne va pas au même endroit, et ce n'est pas la même machine qui calcule.

Manipulation ⑥ · pourquoi tout le monde ne l'a pas chez soi

Combien ça pèse ?

« Sur ma machine » suppose que le modèle y tienne. Les paramètres de la séance précédente sont des nombres : il suffit de compter les octets, comme au chapitre du codage. Choisissez un modèle et une précision.

Modèle
Précision

Quantifier

le même arbitrage qu'au bloc 3

Garder moins de chiffres par paramètre allège le fichier d'autant. C'est exactement le choix fait pour une photo ou un son : moins d'octets, un peu moins de fidélité.

Jusqu'à 8 ou 4 bits, la perte est faible. En dessous, le modèle se dégrade visiblement.

Un mot dont on abuse

« Ouvert » :
trois degrés

Pour télécharger un modèle, encore faut-il qu'on vous le donne. Mais « ouvert » n'est pas un oui ou un non : c'est un curseur à plusieurs crans, et le mot sert souvent d'argument de vente.

Fermé

on n'a que la porte

Le modèle reste chez son éditeur. Vous l'appelez par son API, c'est tout. Impossible de le télécharger, de l'inspecter, ni de le garder : il peut changer ou disparaître du jour au lendemain.

accès : API · poids : non · données : non

Poids ouverts

le cas le plus fréquent

Le fichier des paramètres est téléchargeable. Vous pouvez le faire tourner chez vous, l'étudier, le modifier. Mais les données d'entraînement restent secrètes, et la licence peut interdire des usages.

accès : téléchargement · poids : oui · données : non

Vraiment libre

rare

Poids, code d'entraînement, description des données et licence libre. On peut non seulement s'en servir, mais refaire le modèle et vérifier ce qu'il a lu.

accès : tout · poids : oui · données : documentées

Trois pièges de vocabulaire. Poids ouverts n'est pas open source : sans les données ni le code, on ne peut pas refaire le modèle, seulement l'utiliser. Ouvert n'est pas gratuit : le fichier est gratuit, l'électricité et la machine ne le sont pas. Et fermé n'est pas forcément meilleur : l'écart s'est beaucoup réduit.

Un exemple pour fixer les idées : le lycée veut un assistant qui réponde sur le règlement intérieur. Par l'API, c'est en service la semaine prochaine, mais les questions des élèves sortent de l'établissement. En local, rien ne sort — mais il faut une machine, et le modèle sera plus petit, donc plus maladroit. Le choix est autant juridique que technique.

La question qui ouvre la suite
Et s'il frappait
à ces portes
lui-même ?

Nous savons maintenant qu'une machine peut en appeler une autre avec trois lignes de code. Rien n'empêche de donner cette possibilité au modèle : lui décrire les portes disponibles — une recherche, une calculatrice, l'agenda du lycée — et le laisser choisir laquelle ouvrir. C'est ce qu'on appelle un outil. Et c'est à partir de là qu'un assistant devient un véritable logiciel, avec des couches qu'on peut nommer une par une.

Séance suivante · Anatomie d'un assistant
Activité de la séance · 30 minutes · par groupes de trois ou quatre

Vous êtes
l'API du lycée

Sur papier, sans ordinateur. L'objectif n'est pas d'écrire du code : c'est de découvrir qu'une API est d'abord une décision.

  1. Le service. Choisissez une information du lycée : les menus de la cantine, les horaires du CDI, les salles libres, les résultats du tournoi. Une seule.
  2. La page. Dessinez en trente secondes la page web que vous feriez pour un élève : titre, mise en page, ce qui est gros, ce qui est petit.
  3. Le JSON. Écrivez maintenant la réponse pour un programme. Vous choisissez les noms des champs et leur découpage : date, plat, vegetarien… Attention : ces noms sont un contrat, on ne les changera plus.
  4. L'épreuve du voisin. Échangez vos JSON — pas vos pages. Écrivez trois questions auxquelles le JSON reçu permet de répondre, et une à laquelle il ne permet pas.
  5. La négociation. Rendez la quatrième question à son auteur. Faut-il ajouter un champ ? Lequel ? Qui devra mettre à jour quoi ? C'est exactement le travail d'une équipe technique.
  6. Le bilan. Le lycée veut un assistant qui réponde sur ce service. Choisissez site web, API ou local d'après le tableau de la scène 9, et défendez votre choix en deux phrases — dont une sur les données des élèves.
Séance 11 · à retenir

Internet, le Web et les API

  1. Internet est le réseau — des câbles et des paquets. Le Web est un service qui circule dedans, inventé trente ans plus tard. Le courrier, la visio et les API y circulent aussi.
  2. Une URL se lit en quatre morceaux : protocole, nom de domaine, chemin, paramètres. Le DNS traduit le nom en adresse, puis HTTP transporte la demande et la réponse.
  3. Le Web a connu trois générations : URL (je connais l'adresse) → mots-clés (je cherche des pages) → intention (je formule ma demande). Elles ne se remplacent pas, elles s'empilent.
  4. Une API est une porte faite pour les programmes : mêmes données, sans mise en page. Le format habituel est le JSON, mille fois plus léger qu'une page — et stable, c'est un contrat.
  5. L'API d'un modèle est sans état : elle ne garde rien. Le programme renvoie tout l'historique à chaque appel — d'où le coût qui grimpe, et d'où le fait que la « mémoire » est une fonction de l'application.
  6. Trois façons d'interroger une IA : site web, API, sur sa machine. Elles diffèrent sur qui calcule, où sont les poids, qui voit le texte, et ce qu'on paie.
  7. Un modèle pèse paramètres × octets par paramètre, poids que la quantification divise. Et ouvert est un curseur — fermé, poids ouverts, vraiment libre — jamais un interrupteur.
