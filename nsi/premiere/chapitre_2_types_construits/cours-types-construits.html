Représentation des données Première

Les types construits permettent de regrouper plusieurs valeurs sous un seul nom : p-uplets, tableaux (listes Python), dictionnaires, et les tables de données qu'ils forment ensemble. Le chapitre présente chacun avec ses opérations et le moment où le choisir.

1 Pourquoi des types construits ?

Jusqu'ici, les variables de nos programmes contenaient une seule valeur : un entier, un flottant, une chaîne, un booléen. Ce sont les types simples. Mais la plupart des données du monde réel sont composées de plusieurs valeurs qui n'ont de sens qu'ensemble :

  • Un point dans le plan, c'est deux coordonnées (x, y).
  • Une date, c'est trois nombres : jour, mois, année.
  • Les notes d'une classe, c'est 35 valeurs à l'affilée.
  • Une fiche d'élève, c'est un nom, un prénom, une classe, une adresse, une liste de notes…
  • Une image, c'est une grille de pixels, chacun composé de trois intensités (rouge, vert, bleu).

Les types construits fabriquent, à partir des types simples, de nouveaux types qui mettent plusieurs valeurs ensemble. Python en offre trois principaux, étudiés dans ce chapitre :

TypeSyntaxeIdéeModifiable ?
p-uplet (tuple)(1, 2, 3)Un nombre fixé de valeurs ordonnées.Non
tableau (list)[1, 2, 3]Une suite de valeurs, de longueur variable.Oui
dictionnaire (dict){"a": 1, "b": 2}Un répertoire clé → valeur.Oui

Un même programme utilise souvent les trois : un dictionnaire par élève, dont la clé "notes" renvoie un tableau de p-uplets (matière, note), par exemple.

À quoi ça sert

Nommer une seule variable au lieu de dix, parcourir ses éléments avec une boucle, passer tout un « paquet » de données à une fonction en un seul argument — et, pour les dictionnaires et les listes, modifier ou agrandir le paquet pendant l'exécution.

2 Les p-uplets (tuples)

Définition

Un p-uplet est une suite ordonnée et de longueur fixée de valeurs, écrite entre parenthèses et séparée par des virgules. Un p-uplet est immuable : une fois créé, on ne peut ni ajouter, ni retirer, ni remplacer un élément.

point = (3, 4)                 # un couple (x, y)
date = (7, 10, 2026)            # un triplet (jour, mois, année)
rouge = (255, 0, 0)             # un pixel RGB
vide = ()                        # p-uplet vide
singleton = (5,)              # un p-uplet d'UN élément — la virgule est obligatoire !

On accède à un élément par son indice, numéroté à partir de 0 :

point[0]        # → 3   (le premier élément : l'abscisse)
point[1]        # → 4   (le deuxième : l'ordonnée)
date[2]         # → 2026
len(date)      # → 3   (longueur du p-uplet)
Immuable

Un p-uplet ne se modifie pas. L'instruction point[0] = 5 provoque TypeError: 'tuple' object does not support item assignment. Pour « changer » un point, il faut en recréer un nouveau : point = (5, point[1]).

Deux usages très fréquents

1. Renvoyer plusieurs valeurs d'une fonction : il suffit de renvoyer un p-uplet, et l'appelant peut récupérer chaque composante.

def min_max(t):
    return min(t), max(t)         # les parenthèses sont implicites

mini, maxi = min_max([7, 3, 9, 1])   # mini vaut 1, maxi vaut 9

2. Échanger deux variables en une seule ligne, grâce à l'affectation parallèle :

a, b = 10, 20
a, b = b, a           # a vaut maintenant 20, b vaut 10

3 Les tableaux (listes Python)

Définition

Un tableau est une suite ordonnée de valeurs, écrite entre crochets et séparée par des virgules. En Python, on l'appelle liste (type list). À la différence d'un p-uplet, un tableau est modifiable : on peut changer un élément, en ajouter, en retirer, et sa longueur peut évoluer.

notes = [12, 15, 9, 18, 7]
vide = []                          # tableau vide
melange = ["Alice", 17, True, 3.14]  # on peut mélanger les types
len(notes)                        # → 5

Attention — ces méthodes modifient la liste en place

t.append(4) ne renvoie rien ; c'est la liste t qui a changé. Écrire t = t.append(4) est une erreur courante : t devient alors None !

Parcourir une liste

Deux styles, utilisés selon ce dont on a besoin :

# Parcours par VALEUR : « pour chaque note dans notes »
for note in notes:
    print(note)

# Parcours par INDICE : utile si l'on doit modifier la liste, ou connaître la position
for i in range(len(notes)):
    print("La note numéro", i, "est", notes[i])

Construire une liste à la volée

# Les 10 premiers carrés, avec une boucle
carres = []
for i in range(10):
    carres.append(i * i)         # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# Même chose, en « compréhension » (une ligne)
carres = [i * i for i in range(10)]

4 Alias et copies : un piège à comprendre tôt

Une variable qui désigne une liste ne « contient » pas vraiment la liste : elle en désigne l'emplacement en mémoire. Deux variables peuvent donc désigner la même liste — on parle d'alias.

a = [1, 2, 3]
b = a                 # b et a désignent la MÊME liste
b.append(4)
print(a)              # → [1, 2, 3, 4]  <<-- a a changé aussi !

Après b = a : une seule liste, deux noms

Avec b = a.copy() : deux listes distinctes

Méthode — vraiment copier une liste
  • b = a.copy() ou b = list(a) ou b = a[:] : trois façons équivalentes.
  • Pour une liste de listes, copy() copie la liste « extérieure » mais pas celles qu'elle contient : les sous-listes sont encore partagées. Pour tout dupliquer, il faut la fonction deepcopy du module copy.

Les p-uplets ne connaissent pas ce piège : étant immuables, aucun code ne peut les changer après coup, donc partager ou copier revient au même. C'est l'un de leurs avantages — en particulier quand on veut utiliser une suite de valeurs comme clé d'un dictionnaire (voir partie 6).

5 Les tableaux de tableaux (matrices)

Les éléments d'un tableau peuvent eux-mêmes être des tableaux. On obtient alors une matrice — une grille à deux dimensions, qui sert à représenter un plateau de jeu, une image en niveaux de gris, un terrain, un emploi du temps…

grille = [
    [1, 2, 3],       # ligne 0
    [4, 5, 6],       # ligne 1
    [7, 8, 9],       # ligne 2
]
grille[1]            # → [4, 5, 6]  : la ligne 1
grille[1][2]         # → 6         : ligne 1, colonne 2
grille[0][0] = 99     # modifie une case

La case grille[1][1] est en surbrillance.

Parcourir une matrice

for i in range(len(grille)):           # pour chaque ligne…
    for j in range(len(grille[i])):    # …pour chaque colonne de cette ligne…
        print(grille[i][j], end=" ")
    print()

Créer une matrice remplie

# Une grille 3×4 remplie de 0 — par compréhension (correct) :
m = [[0] * 4 for _ in range(3)]

# ✗ ERREUR CLASSIQUE : les trois lignes seraient la MÊME liste (alias !)
# m = [[0] * 4] * 3   # modifier m[0][0] changerait m[1][0] et m[2][0] aussi
Attention — l'alias dans les matrices

Le piège de la partie 4 revient : [[0] * 4] * 3 crée une seule ligne, répétée trois fois en mémoire. La compréhension [... for _ in range(3)] en crée trois distinctes.

6 Les dictionnaires

Définition

Un dictionnaire (type dict) associe des clés à des valeurs. On y accède à une valeur par sa clé, et non par un indice numérique. Il s'écrit entre accolades, chaque paire sous la forme clé: valeur.

eleve = {
    "nom": "Camille",
    "age": 17,
    "classe": "1ère NSI",
    "notes": [12, 15, 9],
}

eleve["nom"]              # → "Camille"
eleve["age"] = 18           # modification
eleve["email"] = "c@…"      # ajout : une nouvelle paire clé/valeur
del eleve["classe"]       # suppression

"nom" in eleve             # → True   (test d'appartenance d'une CLÉ)
len(eleve)                # → 4      (nombre de paires)
Clé absente

Accéder à une clé qui n'existe pas lève KeyError. Pour tester poliment, on écrit if "age" in eleve:, ou on utilise eleve.get("age", 0) qui renvoie 0 si la clé n'est pas là.

Parcourir un dictionnaire

# Par CLÉ (le plus courant)
for cle in eleve:
    print(cle, ":", eleve[cle])

# Par paire (clé, valeur) — plus pratique si on utilise les deux
for cle, valeur in eleve.items():
    print(cle, "→", valeur)

# Les clés seules, les valeurs seules
list(eleve.keys())        # ["nom", "age", "classe", "notes"]
list(eleve.values())      # ["Camille", 17, "1ère NSI", [12, 15, 9]]

Les clés : des « étiquettes immuables »

Toute valeur immuable peut servir de clé : un entier, un flottant, une chaîne, un booléen, un p-uplet (dont les éléments sont eux-mêmes immuables). Pas une liste, pas un dictionnaire. Chaque clé est unique : réaffecter d["a"] = 2 alors que d["a"] existait déjà remplace la valeur, sans doubler la clé.

Deux usages typiques

Compter des occurrences — par exemple, compter les lettres d'un mot :

mot = "anticonstitutionnellement"
compte = {}
for c in mot:
    if c in compte:
        compte[c] += 1
    else:
        compte[c] = 1
print(compte)                 # {'a': 1, 'n': 5, 't': 5, 'i': 4, ...}

Décrire un objet par ses propriétés : chaque champ est nommé, l'ordre importe peu, on retrouve une valeur en une étape. C'est la représentation la plus souple pour un enregistrement — bien plus que « le troisième élément d'un p-uplet, c'est l'âge ».

7 Les tables de données

En réunissant tableaux et dictionnaires, on fabrique le type de données le plus utilisé en pratique : une table, c'est-à-dire une liste de lignes, chaque ligne étant un enregistrement avec les mêmes champs.

eleves = [
    {"nom": "Alice",   "age": 17, "ville": "Lyon"},
    {"nom": "Bruno",   "age": 16, "ville": "Paris"},
    {"nom": "Chloé",   "age": 17, "ville": "Lyon"},
    {"nom": "David",   "age": 18, "ville": "Rennes"},
]
Indicenomageville

Les trois opérations élémentaires

# 1. Extraire une colonne (ici les âges)
ages = [e["age"] for e in eleves]            # [17, 16, 17, 18]

# 2. Filtrer les lignes (ici les Lyonnais)
lyonnais = [e for e in eleves if e["ville"] == "Lyon"]

# 3. Calculer sur une colonne
age_moyen = sum(e["age"] for e in eleves) / len(eleves)

Lire une table depuis un fichier CSV

Un fichier CSV (comma-separated values) est un tableur « nu » : une ligne de titres, puis une ligne par enregistrement, les champs séparés par des virgules (ou des points-virgules). Le module csv de la bibliothèque standard sait les lire :

import csv

with open("eleves.csv", encoding="utf-8") as f:
    lecteur = csv.DictReader(f)
    eleves = [ligne for ligne in lecteur]      # liste de dictionnaires

print(eleves[0]["nom"])
print(len(eleves), "élèves chargés")

Un détail important : les valeurs lues depuis un fichier CSV sont toujours des chaînes de caractères. Si l'on veut en faire des entiers ou des flottants, il faut les convertir soi-même :

for e in eleves:
    e["age"] = int(e["age"])            # "17" → 17
Une représentation universelle

La plupart des jeux de données que l'on utilisera cette année (notes d'élèves, villes de France, titres musicaux, statistiques sportives…) sont présentés comme des tables de ce type. Le chapitre suivant leur consacrera des opérations plus avancées : recherche, tri, fusion.

8 Choisir le bon type construit

Un bon choix de type construit rend le code plus court, plus lisible et plus rapide. Quelques questions à se poser :

QuestionLe bon type
Combien de valeurs ? Un petit nombre fixé, chacune avec un rôle précis (x et y, jour mois année).p-uplet
Une collection qui va grossir ou rétrécir au fil du programme ; l'ordre compte.liste
On accède aux éléments par leur position (le 3e, le dernier…).liste ou p-uplet
On accède aux éléments par un identifiant non numérique (un nom, un code, une étiquette).dictionnaire
Les données doivent rester intactes (pour servir de clé, par exemple).p-uplet
Un enregistrement avec plusieurs champs nommés (nom, âge, ville…).dictionnaire
Beaucoup d'enregistrements du même type → une table.liste de dictionnaires
Une grille à deux dimensions (image, plateau, carte).liste de listes
Méthode — s'arrêter avant de coder

Avant d'écrire une seule ligne, posez cette question : sur quoi je vais faire mes accès ? Si c'est un numéro de ligne, une liste suffit. Si c'est un nom, un code, une date, un dictionnaire sera bien plus naturel. Un bon type construit évite les boucles inutiles pour « retrouver » une donnée que l'on aurait pu désigner directement.

p-uplet(1, 2, 3) — ordonné, longueur fixée, immuable. Accès par indice. Pour renvoyer plusieurs valeurs, pour échanger.
liste[1, 2, 3] — ordonnée, modifiable, longueur variable. append, pop, insert, remove. Parcourable par valeur ou par indice.

ChoisirPosition → liste. Identifiant → dictionnaire. Nombre fixé de valeurs à rôles précis → p-uplet.
