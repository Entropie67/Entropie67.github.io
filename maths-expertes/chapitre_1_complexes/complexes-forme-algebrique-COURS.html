Présentation
des nombres complexes

Une histoire d'inclusions

Chaque ensemble
en contient un autre

\mathbb{N}\subset\mathbb{Z}\subset\mathbb{D}\subset\mathbb{Q}\subset\mathbb{R}\subset\mathbb{C}

  • \mathbb{N} entiers naturels — 0,\ 7
  • \mathbb{Z} entiers relatifs — -3
  • \mathbb{D} décimaux — 1{,}25
  • \mathbb{Q} rationnels — \tfrac13
  • \mathbb{R} réels — \sqrt2,\ \pi
  • \mathbb{C} complexes — 2+3\mathrm{i}

Pour les curieux : au-delà de \mathbb{C} vivent les quaternions \mathbb{H} (dimension 4, la multiplication n'y est plus commutative !).

Le plan complexe

À chaque point du plan,
un nombre

Le plan est muni d'un repère orthonormé direct (O,\vec u,\vec v). À tout point M(x\,;\,y) on associe le nombre z_M=x+\mathrm{i}\,y.

z_M est l'affixe de M ; M est l'image de z_M.

Le corps ℂ

Un ensemble qui prolonge ℝ

Définition

L'ensemble \mathbb{C} contient \mathbb{R} et vérifie :

  • • une addition et une multiplication qui prolongent celles de \mathbb{R} ;
  • • il existe un élément \mathrm{i} tel que \mathrm{i}^2=\htmlClass{result-tex}{-1} ;
  • • tout z s'écrit de manière unique z=x+\mathrm{i}y avec x,y\in\mathbb{R}.

prolongent … i²=−1 … unique

Vocabulaire

x=\operatorname{Re}(z) : partie réelle · y=\operatorname{Im}(z) : partie imaginaire (un réel !). Si x=0 : imaginaire pur ; si y=0 : réel.

partie réelle · partie imaginaire · imaginaire pur · réel

Conséquence de l'unicité

Égalité de deux complexes

Propriété

Deux complexes sont égaux si et seulement s'ils ont la même partie réelle et la même partie imaginaire :

z=z' \iff \operatorname{Re}(z)=\operatorname{Re}(z') \ \text{ et } \ \operatorname{Im}(z)=\operatorname{Im}(z')
Démonstration — unicité

Si x+\mathrm{i}y=0 avec (x,y)\neq(0,0) : si y\neq0, alors \mathrm{i}=-\tfrac{x}{y}\in\mathbb{R} — absurde. Donc y=0, puis x=0. L'écriture est unique.

Opérations
dans ℂ

Addition et multiplication

On calcule comme dans ℝ,
avec \mathrm{i}^2=-1

Propriété

Pour z=x+\mathrm{i}y et z'=x'+\mathrm{i}y' :

z+z' = (x+x') + \mathrm{i}(y+y')
z\times z' = \htmlClass{result-tex}{(xx'-yy')} + \mathrm{i}\,(xy'+yx')
Démonstration — produit

(x+\mathrm{i}y)(x'+\mathrm{i}y')=xx'+\mathrm{i}xy'+\mathrm{i}yx'+\mathrm{i}^2yy'=(xx'-yy')+\mathrm{i}(xy'+yx') car \mathrm{i}^2=-1.

Applications

Quelques calculs

\mathrm{i}-(3+2\mathrm{i}) = \htmlClass{result-tex}{-3-\mathrm{i}}
(1+\mathrm{i})^2 = 1+2\mathrm{i}+\mathrm{i}^2 = \htmlClass{result-tex}{2\mathrm{i}}
\frac{1-\mathrm{i}}{1+\mathrm{i}} = \frac{(1-\mathrm{i})^2}{(1+\mathrm{i})(1-\mathrm{i})} = \frac{-2\mathrm{i}}{2} = \htmlClass{result-tex}{-\mathrm{i}}

Le dernier calcul annonce la technique de l'expression conjuguée (§3).

Identités remarquables

Elles restent valables dans ℂ

Conséquences
(a+\mathrm{i}b)^2 = a^2-b^2+2\mathrm{i}ab
(a-\mathrm{i}b)^2 = a^2-b^2-2\mathrm{i}ab
(a+\mathrm{i}b)(a-\mathrm{i}b) = \htmlClass{result-tex}{a^2+b^2}

La dernière est la clé pour diviser : le produit d'un complexe par son conjugué est un réel positif.

Conjugué,
inverse et quotient

Conjugué

Le reflet par l'axe réel

Définition

Le conjugué de z=x+\mathrm{i}y est

\bar z = x - \mathrm{i}y

N(\bar z) est le symétrique de M(z) par rapport à l'axe réel.

Propriétés du conjugué

Un outil de calcul

Caractérisations
  • • z\times\bar z = \operatorname{Re}(z)^2+\operatorname{Im}(z)^2
  • • z+\bar z = 2\operatorname{Re}(z)
  • • z-\bar z = 2\mathrm{i}\operatorname{Im}(z)
  • • z\in\mathbb{R}\iff z̄=z
  • • z\in\mathrm{i}\mathbb{R}\iff z̄=−z

z̄=z · z̄=−z

Compatibilité opérations
  • • \overline{z+z'} = \bar z+\bar z'
  • • \overline{z\times z'} = \bar z\times\bar z'
  • • \overline{\left(\tfrac{z}{z'}\right)} = \tfrac{\bar z}{\bar z'}
  • • \overline{z^n} = (\bar z)^n
  • • \overline{kz}=k\bar z (k\in\mathbb{R})
Inverse et quotient

Diviser par l'expression conjuguée

Définition

Pour z\neq0, l'inverse \tfrac1z vérifie z\times\tfrac1z=1. On multiplie par le conjugué du dénominateur :

\frac1z=\frac{\bar z}{z\bar z}=\frac{x-\mathrm{i}y}{x^2+y^2}
Exemple
\frac{2+3\mathrm{i}}{3-\mathrm{i}}=\frac{(2+3\mathrm{i})(3+\mathrm{i})}{(3-\mathrm{i})(3+\mathrm{i})}=\frac{3+11\mathrm{i}}{10}=\htmlClass{result-tex}{0{,}3+1{,}1\,\mathrm{i}}
Méthode

Résoudre une équation avec \bar z

Deux cas

1. Si \bar z intervient seul : on isole \bar z comme dans une équation du 1er degré, puis on conjugue (\overline{\bar z}=z).

2. Si z et \bar z interviennent : on pose z=x+\mathrm{i}y et on identifie parties réelle et imaginaire.

Exemple — cas 2

2z+\mathrm{i}\bar z=5-2\mathrm{i} avec z=x+\mathrm{i}y donne \begin{cases}2x+y=5\\ x+2y=-2\end{cases} d'où z=\htmlClass{result-tex}{4-3\mathrm{i}}.

Équations
du deuxième degré

Discriminant

Toujours résoluble dans ℂ

Théorème

az^2+bz+c=0 (a,b,c réels, a\neq0), \Delta=b^2-4ac :

  • • \Delta>0 : deux racines réelles \tfrac{-b\pm\sqrt\Delta}{2a}
  • • \Delta=0 : une racine \tfrac{-b}{2a}
  • • \Delta<0 : deux racines complexes conjuguées z=\htmlClass{result-tex}{\dfrac{-b\pm\mathrm{i}\sqrt{-\Delta}}{2a}}

complexes conjuguées

Exemple

Cas \Delta<0

Résoudre z^2+z+1=0.

\Delta = 1-4 = -3 < 0
z_1=\frac{-1-\mathrm{i}\sqrt3}{2},\quad z_2=\bar{z_1}=\frac{-1+\mathrm{i}\sqrt3}{2}
Démonstration (Δ<0)

Forme canonique : a\!\left(z+\tfrac{b}{2a}\right)^2-\tfrac{\Delta}{4a}. Comme \Delta<0, on écrit \Delta=\mathrm{i}^2(-\Delta) et on factorise par identité remarquable, d'où les deux racines conjuguées.

Polynômes
de degré n

Racines et factorisation

Une racine, un facteur

Propriété

Pour un polynôme P de degré n\geq1 et a\in\mathbb{C} :

a\text{ racine de }P \iff P(z)=(z-a)\,Q(z)

Q est de degré n−1.

n−1

Deux conséquences

• Un polynôme de degré n admet au plus n racines.
• On peut résoudre par racine évidente puis factorisation.

au plus n

L'outil clé

La factorisation de z^n-a^n

Identité (télescopage)
z^n-a^n=(z-a)\sum_{k=0}^{n-1} z^{\,n-1-k}a^{k}

En développant, tous les termes se simplifient deux à deux sauf z^n et -a^n. C'est cette identité qui fonde la propriété « une racine → un facteur ».

Relations coefficients–racines

Les formules de Viète

Propriété (admise)

Pour P(z)=\sum_{k=0}^{n}\alpha_k z^k (degré n, \alpha_n\neq0) :

\text{somme des racines} = -\frac{\alpha_{n-1}}{\alpha_n}
\text{produit des racines} = (-1)^n\frac{\alpha_0}{\alpha_n}
Application

Racine évidente + Viète

P(z)=z^3-2z^2+z-2. Racine évidente : P(2)=0.

z_1+z_2 = 0 \quad\text{et}\quad z_1 z_2 = 1 \;\Rightarrow\; z_1=\mathrm{i},\ z_2=-\mathrm{i}
P(z)=\htmlClass{result-tex}{(z-\mathrm{i})(z+\mathrm{i})(z-2)}

Dans \mathbb{R} : P(z)=(z^2+1)(z-2).
