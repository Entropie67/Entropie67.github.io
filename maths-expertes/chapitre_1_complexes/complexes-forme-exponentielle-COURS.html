Forme trigonométrique
et exponentielle

Après la forme algébrique z = x + \mathrm{i}y, voici la deuxième façon de décrire un complexe : par son module (distance à l'origine) et son argument (angle). Elle se révèle imbattable pour multiplier, élever à une puissance, et pour exprimer les transformations géométriques. Le miracle : l'écriture exponentielle z = r\,\mathrm{e}^{\mathrm{i}\theta}.

1

Module
d'un complexe

Définition

Une distance à l'origine

Définition

Soit z = x + \mathrm{i}y un complexe d'image M(x\,;\,y) dans le plan complexe. Le module de z, noté |z|, est la distance OM :

|z| = \sqrt{x^2 + y^2}
Propriétés immédiates
  • |z| \geq 0 et |z| = 0 \iff z = 0.
  • Si z\in\mathbb{R}, |z| coïncide avec la valeur absolue.
  • Si z est imaginaire pur \mathrm{i}y, alors |z| = |y|.
  • |\bar z| = |z| (le conjugué a même module).
  • |{-z}| = |z|.
La propriété clé

Module et conjugué

Propriété fondamentale

Pour tout complexe z :

|z|^2 = z\,\bar z

C'est l'identité à retenir pour passer d'un module à des produits, et pour démontrer les propriétés qui suivent.

Démonstration — en une ligne

Si z = x + \mathrm{i}y, alors z\,\bar z = (x+\mathrm{i}y)(x-\mathrm{i}y) = x^2 - (\mathrm{i}y)^2 = x^2 + y^2 = |z|^2. ■

Exemple

Pour z = 3 + 2\mathrm{i} : z\,\bar z = (3+2\mathrm{i})(3-2\mathrm{i}) = 9 + 4 = 13, donc |z| = \sqrt{13}.

Opérations

Le module se comporte
comme la valeur absolue

Règles opératoires

Pour tous complexes z, z' (avec z' \neq 0 pour le quotient) et tout entier naturel n :

|z \times z'| = |z| \times |z'| \qquad \left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|} \qquad |z^n| = |z|^n
Démonstration — produit

On utilise |w|^2 = w\bar w et le fait que \overline{zz'} = \bar z\,\bar{z'} :

|zz'|^2 = zz'\overline{zz'} = zz'\,\bar z\,\bar{z'} = (z\bar z)(z'\bar{z'}) = |z|^2|z'|^2

D'où |zz'| = |z|\,|z'| (modules positifs). ■

Inégalité triangulaire

Pour tous z, z' : |z + z'| \leq |z| + |z'|, avec égalité si et seulement si l'un est un multiple positif de l'autre. Interprétation : la longueur d'un côté d'un triangle n'excède jamais la somme des deux autres.

2

Argument
d'un complexe

Définition

L'angle qu'on fait
avec l'axe réel

Définition

Soit z un complexe non nul d'image M. Tout nombre réel \theta tel que \theta = (\overrightarrow{u}, \overrightarrow{OM})\;[2\pi] est un argument de z, noté \arg(z).

Deux arguments de z diffèrent toujours d'un multiple de 2\pi. L'argument principal est celui qui appartient à ]-\pi\,;\,\pi].

Attention — 0 n'a pas d'argument

Le vecteur nul \overrightarrow{OO} ne définit pas de direction. On ne parle d'argument que pour z \neq 0.

Méthode — trouver un argument
  1. Calculer r = |z|.
  2. Écrire \dfrac{z}{r} = \dfrac{x}{r} + \mathrm{i}\dfrac{y}{r}. Les parties réelle et imaginaire sont alors \cos\theta et \sin\theta.
  3. Reconnaître l'angle correspondant dans le cercle trigonométrique.
3

Forme
trigonométrique

Définition

Rendre module et argument
visibles dans l'écriture

Théorème

Tout complexe z \neq 0 s'écrit de manière unique (à 2\pi près sur \theta) sous la forme :

\boxed{\, z = r\,\bigl(\cos\theta + \mathrm{i}\sin\theta\bigr) \,}

où r = |z| > 0 est le module et \theta = \arg(z) l'argument. C'est la forme trigonométrique de z.

Démonstration

Soit z = x + \mathrm{i}y \neq 0, de module r = \sqrt{x^2+y^2}. Le point M(x,y) est sur le cercle de rayon r centré en O. Si \theta est l'angle du vecteur \overrightarrow{OM} avec \vec u, alors par définition du cosinus et du sinus sur ce cercle :

x = r\cos\theta \quad\text{et}\quad y = r\sin\theta

D'où z = r\cos\theta + \mathrm{i}\, r\sin\theta = r(\cos\theta + \mathrm{i}\sin\theta). ■

Passages à faire

Algébrique ↔ trigonométrique

Alg → trigo (ex. z = 1 + i)
  1. r = |z| = \sqrt{1^2 + 1^2} = \sqrt 2
  2. \dfrac{z}{r} = \dfrac{1}{\sqrt 2} + \mathrm{i}\,\dfrac{1}{\sqrt 2}
  3. \cos\theta = \sin\theta = \dfrac{\sqrt 2}{2}
  4. D'où \theta = \dfrac{\pi}{4}
z = \sqrt 2 \left(\cos\tfrac{\pi}{4} + \mathrm{i}\sin\tfrac{\pi}{4}\right)
Trigo → alg (ex. r = 2, θ = π/3)
  1. \cos\tfrac{\pi}{3} = \tfrac12, \sin\tfrac{\pi}{3} = \tfrac{\sqrt 3}{2}
  2. D'où z = 2\!\left(\tfrac12 + \mathrm{i}\tfrac{\sqrt 3}{2}\right)
  3. = 1 + \mathrm{i}\sqrt 3
Le miracle de la forme trigo

Multiplier,
c'est multiplier les modules
et additionner les arguments

Propriétés — module et argument d'un produit

Pour tous z, z' non nuls :

|z\,z'| = |z|\,|z'| \qquad \arg(z\,z') = \arg(z) + \arg(z')\;[2\pi]

Et par conséquent, pour tout entier n et z \neq 0 :

|z^n| = |z|^n \qquad \arg(z^n) = n\,\arg(z)\;[2\pi]

Pour l'inverse et le quotient (z' \neq 0) :

\arg\!\left(\tfrac{1}{z'}\right) = -\arg(z') \qquad \arg\!\left(\tfrac{z}{z'}\right) = \arg(z) - \arg(z')
Démonstration par le produit

Les formules d'addition
à l'œuvre

Produit en forme trigonométrique

Soient z = r(\cos\theta + \mathrm{i}\sin\theta) et z' = r'(\cos\theta' + \mathrm{i}\sin\theta'). Alors :

z\,z' = r\,r'\,(\cos\theta + \mathrm{i}\sin\theta)(\cos\theta' + \mathrm{i}\sin\theta')

On développe :

= r\,r'\,\bigl[(\cos\theta\cos\theta' - \sin\theta\sin\theta') + \mathrm{i}(\sin\theta\cos\theta' + \cos\theta\sin\theta')\bigr]

Et on reconnaît les formules de cos(a+b) et sin(a+b) :

z\,z' = r\,r'\,\bigl(\cos(\theta+\theta') + \mathrm{i}\sin(\theta+\theta')\bigr)

Autrement dit : le produit a pour module rr' et pour argument \theta + \theta'. ■

4

Forme
exponentielle

Une notation géniale

eiθ au lieu de cos θ + i sin θ

Notation d'Euler

Pour tout réel \theta, on pose :

\boxed{\,\mathrm{e}^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta\,}

Tout complexe z \neq 0 admet alors une forme exponentielle :

z = r\,\mathrm{e}^{\mathrm{i}\theta} \quad\text{où}\quad r = |z|,\ \theta = \arg(z)
Pourquoi « exponentielle » ?

Parce qu'elle se comporte exactement comme l'exponentielle réelle : \mathrm{e}^{\mathrm{i}\theta} \cdot \mathrm{e}^{\mathrm{i}\theta'} = \mathrm{e}^{\mathrm{i}(\theta+\theta')}. C'est précisément ce que dit la formule du produit démontrée à l'instant.

Règles de calcul

L'exponentielle complexe
obéit aux mêmes règles que l'exponentielle réelle

Propriétés

Pour tous réels \theta, \theta' et tout entier n\in\mathbb{Z} :

\mathrm{e}^{\mathrm{i}\theta} \cdot \mathrm{e}^{\mathrm{i}\theta'} = \mathrm{e}^{\mathrm{i}(\theta+\theta')}
\dfrac{1}{\mathrm{e}^{\mathrm{i}\theta}} = \mathrm{e}^{-\mathrm{i}\theta} \qquad \overline{\mathrm{e}^{\mathrm{i}\theta}} = \mathrm{e}^{-\mathrm{i}\theta}
\bigl(\mathrm{e}^{\mathrm{i}\theta}\bigr)^n = \mathrm{e}^{\mathrm{i}n\theta}

Et pour deux complexes z = r\mathrm{e}^{\mathrm{i}\theta} et z' = r'\mathrm{e}^{\mathrm{i}\theta'} :

z\,z' = r r'\,\mathrm{e}^{\mathrm{i}(\theta+\theta')} \qquad \dfrac{z}{z'} = \dfrac{r}{r'}\,\mathrm{e}^{\mathrm{i}(\theta-\theta')}
z^n = r^n\,\mathrm{e}^{\mathrm{i}n\theta} \qquad \bar z = r\,\mathrm{e}^{-\mathrm{i}\theta}
Formule de De Moivre

Une puissance se calcule
sans développer

Formule de De Moivre

Pour tout \theta\in\mathbb{R} et tout n\in\mathbb{Z} :

\boxed{\,\bigl(\cos\theta + \mathrm{i}\sin\theta\bigr)^n = \cos(n\theta) + \mathrm{i}\sin(n\theta)\,}

C'est juste (\mathrm{e}^{\mathrm{i}\theta})^n = \mathrm{e}^{\mathrm{i}n\theta} écrit sous forme trigonométrique.

Exemple — calcul de (1+i)⁸

Avec la forme algébrique, c'est long. Avec la forme exponentielle :

  • 1 + \mathrm{i} = \sqrt 2\,\mathrm{e}^{\mathrm{i}\pi/4}
  • (1+\mathrm{i})^8 = (\sqrt 2)^8\,\mathrm{e}^{\mathrm{i}\cdot 8\pi/4} = 16\,\mathrm{e}^{2\mathrm{i}\pi} = 16

On trouve 16, un réel pur, en trois lignes.

La plus belle formule des mathématiques

Dans la formule \mathrm{e}^{\mathrm{i}\theta}, posons \theta = \pi : on obtient \mathrm{e}^{\mathrm{i}\pi} = \cos\pi + \mathrm{i}\sin\pi = -1. Soit :

\mathrm{e}^{\mathrm{i}\pi} + 1 = 0

L'identité d'Euler, qui réunit en une seule équation les cinq constantes les plus fondamentales : 0, 1, \mathrm{i}, \pi et \mathrm{e}.

5

Formules d'Euler
et applications

Les deux formules à savoir

cos et sin,
exprimés en exponentielles

Formules d'Euler

Pour tout réel \theta :

\cos\theta = \dfrac{\mathrm{e}^{\mathrm{i}\theta} + \mathrm{e}^{-\mathrm{i}\theta}}{2} \qquad \sin\theta = \dfrac{\mathrm{e}^{\mathrm{i}\theta} - \mathrm{e}^{-\mathrm{i}\theta}}{2\mathrm{i}}
Démonstration

Par définition : \mathrm{e}^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta et \mathrm{e}^{-\mathrm{i}\theta} = \cos\theta - \mathrm{i}\sin\theta.

  • Somme : \mathrm{e}^{\mathrm{i}\theta} + \mathrm{e}^{-\mathrm{i}\theta} = 2\cos\theta, d'où la formule pour \cos\theta.
  • Différence : \mathrm{e}^{\mathrm{i}\theta} - \mathrm{e}^{-\mathrm{i}\theta} = 2\mathrm{i}\sin\theta, d'où la formule pour \sin\theta. ■
Application 1

Linéariser cos²θ et sin²θ

Méthode

« Linéariser » \cos^p\theta\sin^q\theta, c'est l'exprimer comme combinaison linéaire de \cos(k\theta) et \sin(k\theta) (plutôt que des puissances). C'est utile en primitive, en intégration, en physique.

Linéarisation de cos²θ

On part de la formule d'Euler et on développe le carré :

\cos^2\theta = \left(\tfrac{\mathrm{e}^{\mathrm{i}\theta} + \mathrm{e}^{-\mathrm{i}\theta}}{2}\right)^2 = \tfrac{1}{4}\left(\mathrm{e}^{2\mathrm{i}\theta} + 2 + \mathrm{e}^{-2\mathrm{i}\theta}\right)

On regroupe \mathrm{e}^{2\mathrm{i}\theta} + \mathrm{e}^{-2\mathrm{i}\theta} = 2\cos(2\theta) :

\cos^2\theta = \tfrac{1}{4}\bigl(2\cos(2\theta) + 2\bigr) = \tfrac{1 + \cos(2\theta)}{2}

De la même façon : \sin^2\theta = \dfrac{1 - \cos(2\theta)}{2}.

Application 2

Linéariser sin³θ

Même méthode, cube
\sin^3\theta = \left(\tfrac{\mathrm{e}^{\mathrm{i}\theta} - \mathrm{e}^{-\mathrm{i}\theta}}{2\mathrm{i}}\right)^3 = \tfrac{1}{(2\mathrm{i})^3}\bigl(\mathrm{e}^{\mathrm{i}\theta} - \mathrm{e}^{-\mathrm{i}\theta}\bigr)^3

On développe (binôme) :

\bigl(\mathrm{e}^{\mathrm{i}\theta} - \mathrm{e}^{-\mathrm{i}\theta}\bigr)^3 = \mathrm{e}^{3\mathrm{i}\theta} - 3\mathrm{e}^{\mathrm{i}\theta} + 3\mathrm{e}^{-\mathrm{i}\theta} - \mathrm{e}^{-3\mathrm{i}\theta}

On regroupe par paires conjuguées :

= 2\mathrm{i}\sin(3\theta) - 6\mathrm{i}\sin\theta

Avec (2\mathrm{i})^3 = -8\mathrm{i}, finalement :

\sin^3\theta = \tfrac{2\mathrm{i}\sin(3\theta) - 6\mathrm{i}\sin\theta}{-8\mathrm{i}} = \tfrac{3\sin\theta - \sin(3\theta)}{4}
Application 3

Retrouver les formules
d'addition

De De Moivre à cos(3θ)

On applique (cos\theta + \mathrm{i}\sin\theta)^3 = \cos(3\theta) + \mathrm{i}\sin(3\theta). On développe le cube :

(\cos\theta + \mathrm{i}\sin\theta)^3 = \cos^3\theta + 3\mathrm{i}\cos^2\theta\sin\theta - 3\cos\theta\sin^2\theta - \mathrm{i}\sin^3\theta

On identifie parties réelle et imaginaire :

\cos(3\theta) = \cos^3\theta - 3\cos\theta\sin^2\theta
\sin(3\theta) = 3\cos^2\theta\sin\theta - \sin^3\theta

Avec \sin^2\theta = 1 - \cos^2\theta, on retrouve les formules classiques \cos(3\theta) = 4\cos^3\theta - 3\cos\theta et \sin(3\theta) = 3\sin\theta - 4\sin^3\theta.

6

Interprétation
géométrique

Lecture d'une multiplication

Multiplier par un complexe,
c'est une transformation du plan

Propriété

Soit a = \rho\,\mathrm{e}^{\mathrm{i}\alpha} un complexe non nul. L'application z \mapsto a z transforme chaque point M(z) en M'(a z) :

  • le module est multiplié par \rho : homothétie de centre O et de rapport \rho ;
  • l'argument est augmenté de \alpha : rotation de centre O et d'angle \alpha.
Trois cas remarquables
  • Multiplier par \mathrm{i} (\rho = 1, \alpha = \pi/2) : rotation d'un quart de tour direct autour de O.
  • Multiplier par -1 : rotation d'un demi-tour (symétrie centrale par rapport à O).
  • Multiplier par \mathrm{e}^{\mathrm{i}\pi/3} : rotation d'un sixième de tour (60°), sans changement de module.
Application

Un triangle équilatéral

Problème

Soient A, B, C trois points d'affixes a, b, c. Montrer qu'ils forment un triangle équilatéral direct si et seulement si :

c - a = \mathrm{e}^{\mathrm{i}\pi/3}\,(b - a)
Lecture

b - a et c - a sont les affixes des vecteurs \overrightarrow{AB} et \overrightarrow{AC}. L'équation dit : \overrightarrow{AC} s'obtient à partir de \overrightarrow{AB} par rotation de 60°. Et puisque le facteur a pour module 1, les deux vecteurs ont même longueur : AB = AC. Avec un angle de 60° entre eux, le triangle est équilatéral. ■

À retenir

Les complexes transforment les problèmes de géométrie plane en calculs algébriques : angles → arguments, longueurs → modules, translations → additions, rotations ↔ multiplications. C'est la grande force du chapitre.

L'essentiel du chapitre

Module

|z| = \sqrt{x^2 + y^2}, distance OM. Formule clé : |z|^2 = z\bar z. Multiplicatif : |zz'| = |z||z'|.

Argument

Angle (\vec u, \overrightarrow{OM}). Défini modulo 2\pi, principal dans ]-\pi,\pi]. Non défini pour z = 0.

Forme trigonométrique

z = r(\cos\theta + \mathrm{i}\sin\theta), avec r = |z| et \theta = \arg(z).

Forme exponentielle

z = r\,\mathrm{e}^{\mathrm{i}\theta}. Produit : r r'\,\mathrm{e}^{\mathrm{i}(\theta+\theta')}. Puissance : r^n\,\mathrm{e}^{\mathrm{i}n\theta}.

De Moivre

(\cos\theta + \mathrm{i}\sin\theta)^n = \cos(n\theta) + \mathrm{i}\sin(n\theta).

Euler

\cos\theta = \tfrac{\mathrm{e}^{\mathrm{i}\theta}+\mathrm{e}^{-\mathrm{i}\theta}}{2}, \sin\theta = \tfrac{\mathrm{e}^{\mathrm{i}\theta}-\mathrm{e}^{-\mathrm{i}\theta}}{2\mathrm{i}}. Pour linéariser.

Géométrie

Multiplier par \rho\mathrm{e}^{\mathrm{i}\alpha} = homothétie de rapport \rho composée d'une rotation d'angle \alpha centrée en O.

Identité d'Euler

\mathrm{e}^{\mathrm{i}\pi} + 1 = 0. Les cinq constantes fondamentales en une égalité.
