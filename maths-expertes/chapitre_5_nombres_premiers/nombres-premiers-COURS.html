L'ensemble
des nombres premiers

Définition

Deux diviseurs,
pas un de plus

Définition

Un entier p\in\mathbb{N} est premier lorsque p \geq 2 et que ses seuls diviseurs positifs sont 1 et lui-même.

Les entiers n \geq 2 non premiers sont dits composés. 1 n'est ni premier, ni composé.

premiers2, 3, 5, 7, 11
suivants13, 17, 19, 23, 29
composés4=2², 6=2·3, 9=3²
particulier2 est le seul pair
Un détail important

La convention « 1 n'est pas premier » n'est pas arbitraire : elle garantit l'unicité de la décomposition en facteurs premiers (section 2). Sans elle, on écrirait tantôt 6 = 2\times 3, tantôt 6 = 1\times 2\times 3, tantôt 6 = 1\times 1\times 2\times 3…

Trouver les premiers

Le crible d'Ératosthène

Pour trouver tous les premiers jusqu'à N : on écrit tous les entiers de 2 à N. On entoure 2, on raye tous ses multiples (sauf lui). On entoure le plus petit non rayé (3), on raye ses multiples. Et ainsi de suite jusqu'à \sqrt{N}.

Astuce clé

Pour tester si n est premier, il suffit d'essayer les diviseurs jusqu'à \sqrt{n}. Si n = ab avec 1 < a \leq b, alors a^2 \leq ab = n, donc a \leq \sqrt n.

Théorème d'Euclide

Les nombres premiers
sont en nombre infini

Théorème (Euclide, 300 av. J.-C.)

Il existe une infinité de nombres premiers.

Démonstration par l'absurde

Supposons qu'il n'y ait qu'un nombre fini de nombres premiers : p_1, p_2, \ldots, p_n. Considérons le nombre :

N = p_1 \times p_2 \times \cdots \times p_n + 1

N est entier et N \geq 2. Il admet donc un diviseur premier p (voir slide suivante). Mais p ne peut être aucun des p_i : si p = p_i, alors p divise le produit p_1\cdots p_n, et comme il divise aussi N, par soustraction il divise 1 — absurde. Donc p est un nombre premier qui n'était pas dans notre liste. ■

Lemme utile

Tout entier a un diviseur premier

Propriété

Tout entier n \geq 2 admet au moins un diviseur premier.

Démonstration

Soit n \geq 2. L'ensemble des diviseurs de n supérieurs ou égaux à 2 est non vide (il contient n) et est une partie non vide de \mathbb{N} : il admet un plus petit élément, notons-le p.

Montrons que p est premier. Si p admettait un diviseur d avec 1 < d < p, alors d serait aussi un diviseur de n (par transitivité) supérieur ou égal à 2, et strictement plus petit que p — ce qui contredit la minimalité de p. Donc p n'a aucun diviseur autre que 1 et lui-même : p est premier. ■

Décomposition
en facteurs premiers

Théorème fondamental

Chaque entier a une unique
« carte d'identité » première

Théorème fondamental de l'arithmétique

Tout entier n \geq 2 se décompose de manière unique, à l'ordre près des facteurs, comme un produit de nombres premiers :

n = p_1^{\alpha_1} \times p_2^{\alpha_2} \times \cdots \times p_k^{\alpha_k}

où p_1 < p_2 < \cdots < p_k sont des nombres premiers distincts et \alpha_i \in \mathbb{N}^*.

En pratique

Comment décomposer
à la main

Méthode

On divise n successivement par les nombres premiers, dans l'ordre croissant, tant que c'est possible. Dès qu'un premier p ne divise plus, on passe au suivant.

360 ÷ 2 = 180
180 ÷ 2 = 90
 90 ÷ 2 = 45
 45 ÷ 3 = 15
 15 ÷ 3 = 5
  5 ÷ 5 = 1
──────────────
360 = 2³ × 3² × 5
Applications immédiates
  • Le nombre de diviseurs de n = p_1^{\alpha_1}\cdots p_k^{\alpha_k} est (\alpha_1 + 1)(\alpha_2+1)\cdots(\alpha_k+1). Pour 360 = 2^3\cdot 3^2\cdot 5 : 4\times 3\times 2 = 24 diviseurs.
  • Le PGCD de deux entiers décomposés est le produit des facteurs communs avec le plus petit exposant ; le PPCM avec le plus grand.
Application

PGCD par décomposition

Exemple

Calculons le PGCD de 360 et 756.

360 = 2^3 \times 3^2 \times 5

756 = 2^2 \times 3^3 \times 7

Pour chaque premier, on prend le plus petit exposant :

  • pour 2 : min(3, 2) = 2 → 2^2
  • pour 3 : min(2, 3) = 2 → 3^2
  • 5 et 7 n'apparaissent pas dans les deux

D'où \mathrm{pgcd}(360, 756) = 2^2 \times 3^2 = 36.

Vérification Euclide : 756 = 360×2 + 36, 360 = 36×10 + 0. Pgcd = 36. ✓

3

Petit théorème
de Fermat

Énoncé

Une congruence qui ne dépend que du premier p

Théorème — Fermat (1640)

Soit p un nombre premier et a un entier. Alors :

a^{p} \equiv a \pmod{p}

Si de plus a n'est pas divisible par p (c'est-à-dire \mathrm{pgcd}(a,p)=1), on peut simplifier par a :

a^{p-1} \equiv 1 \pmod{p}
p=5, a=22⁵ = 32 ≡ 2 (5)2⁴ = 16 ≡ 1 (5)
p=7, a=33⁶ = 729 ≡ 1 (7)729 = 104×7 + 1
p=11, a=55¹⁰ ≡ 1 (11)
attention4 non premier3⁴ = 81 ≡ 1 (4) mais ce n'est pas Fermat
Application

Puissances modulo un premier

Exemple

Calculons 2^{100} \bmod 13. 13 est premier et \mathrm{pgcd}(2,13)=1, donc par Fermat :

2^{12} \equiv 1 \pmod{13}

On divise 100 par 12 : 100 = 12\times 8 + 4. D'où :

2^{100} = (2^{12})^{8} \times 2^{4} \equiv 1^{8}\times 16 \equiv 16 \equiv 3 \pmod{13}

Donc 2^{100} a pour reste 3 dans la division par 13. Sans Fermat, il aurait fallu calculer 2^{100} \approx 10^{30} puis le réduire.

Démonstration

Un argument par bijection

Preuve (cas a \wedge p = 1)

Considérons les p-1 entiers a, 2a, 3a, \ldots, (p-1)a, pris modulo p.

  • Aucun n'est \equiv 0 \pmod p (sinon p \mid ka, puis par Gauss p \mid k, impossible pour 1 \leq k \leq p-1).
  • Deux à deux distincts modulo p : si i a \equiv j a, alors (par Gauss, car a\wedge p = 1) i\equiv j \pmod p, donc i = j.

Ces p-1 entiers forment donc une permutation de \{1, 2, \ldots, p-1\} modulo p. Leur produit vaut :

a \cdot 2a \cdots (p-1)a = a^{p-1} \cdot (p-1)! \equiv 1 \cdot 2 \cdots (p-1) = (p-1)! \pmod p

Comme (p-1)! est premier avec p, on simplifie : a^{p-1} \equiv 1 \pmod p. ■

TP 1

Test de primalité

Deux approches : un test exact par divisions successives, et un test probabiliste appuyé sur le petit théorème de Fermat.

1. Test exact — divisions jusqu'à √n

def est_premier(n):
    """Renvoie True si n est premier (n >= 2)."""
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    k = 3
    while k * k <= n:              # on s'arrête à sqrt(n)
        if n % k == 0:
            return False
        k += 2                     # on saute les pairs
    return True

est_premier(2)        # → True
est_premier(15)       # → False (15 = 3×5)
est_premier(997)      # → True
est_premier(1000003)  # → True  (environ 1 ms)

2. Décomposition en facteurs premiers

def decomposition(n):
    """Renvoie la liste des facteurs premiers de n, avec répétitions."""
    facteurs = []
    d = 2
    while d * d <= n:
        while n % d == 0:
            facteurs.append(d)
            n //= d
        d += 1
    if n > 1:
        facteurs.append(n)
    return facteurs

decomposition(60)     # → [2, 2, 3, 5]
decomposition(360)    # → [2, 2, 2, 3, 3, 5]
decomposition(997)    # → [997]
decomposition(2026)   # → [2, 1013]

3. Test probabiliste de Fermat

import random

def test_fermat(n, k=10):
    """Teste la primalité de n en répétant k fois le petit théorème de Fermat.
    Renvoie True (probablement premier) ou False (certainement composé)."""
    if n < 4:
        return n == 2 or n == 3
    if n % 2 == 0:
        return False
    for _ in range(k):
        a = random.randint(2, n - 2)
        if pow(a, n - 1, n) != 1:   # Fermat violé → composé
            return False
    return True

test_fermat(1_000_003)         # → True
test_fermat(10**20 + 39)     # → True (grand premier)
test_fermat(10**20)          # → False (évidemment composé)
À savoir

La fonction pow(a, n-1, n) calcule a^{n-1} \bmod n en temps logarithmique grâce à l'exponentiation rapide — essentiel pour tester des nombres de 100 ou 1000 chiffres.

Limite — les nombres de Carmichael

Certains entiers composés passent le test de Fermat pour tout a premier avec eux : par exemple 561 = 3×11×17. Ces nombres (de Carmichael) sont rares, mais pour un test vraiment sûr sur de grands nombres, on utilise un raffinement : le test de Miller-Rabin.

TP 2

Chiffrement RSA

RSA (Rivest–Shamir–Adleman, 1977) est un système de cryptographie à clé publique : on peut envoyer un message chiffré à quelqu'un sans qu'il ait fallu partager une clé secrète au préalable. Il repose entièrement sur le petit théorème de Fermat et sur un fait expérimental : factoriser un grand entier est très difficile, alors que le multiplier est facile.

1. Principe

Les trois clés
  1. Choisir deux grands nombres premiers p et q, calculer n = p \times q.
  2. Calculer \varphi(n) = (p-1)(q-1) (indicatrice d'Euler : nombre d'entiers premiers avec n).
  3. Choisir un entier e premier avec \varphi(n) (clé publique de chiffrement).
  4. Calculer d, l'inverse de e modulo \varphi(n), par Bézout (clé privée de déchiffrement).

Clé publique : (n, e), partagée au monde entier. Clé privée : d, gardée secrète.

Chiffrer / déchiffrer

Pour chiffrer un message m (converti en entier 0 \leq m < n) : on calcule c = m^e \bmod n.

Pour déchiffrer : on calcule m = c^d \bmod n. La correction du système vient de Fermat : m^{ed} \equiv m \pmod n.

2. Les briques Python

def pgcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

def euclide_etendu(a, b):
    """Renvoie (d, u, v) tels que a*u + b*v = d = pgcd(a, b)."""
    if b == 0:
        return a, 1, 0
    d, u1, v1 = euclide_etendu(b, a % b)
    return d, v1, u1 - (a // b) * v1

def inverse_mod(e, phi):
    """Renvoie d tel que e*d ≡ 1 (mod phi)."""
    _, u, _ = euclide_etendu(e, phi)
    return u % phi

3. Génération des clés et chiffrement

def genere_cles(p, q, e=65537):
    """Génère une paire de clés RSA à partir de deux premiers p et q."""
    n = p * q
    phi = (p - 1) * (q - 1)
    assert pgcd(e, phi) == 1, "e doit être premier avec phi(n)"
    d = inverse_mod(e, phi)
    return (n, e), (n, d)         # (publique, privée)

def chiffrer(m, cle_pub):
    n, e = cle_pub
    return pow(m, e, n)         # exponentiation rapide

def dechiffrer(c, cle_priv):
    n, d = cle_priv
    return pow(c, d, n)

4. Exemple complet avec des petits premiers

# Alice choisit deux premiers (petits, pour l'exemple)
p, q = 61, 53
pub, priv = genere_cles(p, q, e=17)
pub        # → (3233, 17)   publié par Alice
priv       # → (3233, 2753) gardé secret par Alice

# Bob chiffre le message m = 65 pour Alice (il n'a que la clé publique)
c = chiffrer(65, pub)
c          # → 2790

# Alice déchiffre avec sa clé privée
m = dechiffrer(c, priv)
m          # → 65  ✓

5. Toutes les étapes à la main sur l'exemple

Déroulé pédagogique
  • p = 61, q = 53 → n = 3233, \varphi(n) = 60 \times 52 = 3120.
  • e = 17 → on vérifie \mathrm{pgcd}(17, 3120) = 1 ✓ (17 est premier et ne divise pas 3120).
  • Bézout (Euclide étendu) : 17 \times 2753 - 3120 \times 15 = 1, donc d = 2753.
  • Chiffrement de 65 : 65^{17} \bmod 3233 = 2790.
  • Déchiffrement : 2790^{2753} \bmod 3233 = 65. ✓
Pourquoi c'est sûr

Pour casser RSA, un attaquant qui connaît (n, e) doit retrouver d. Pour cela, il lui faut \varphi(n) = (p-1)(q-1), donc p et q : il doit factoriser n. Avec n de 2048 bits (environ 617 chiffres), aucun algorithme connu ne sait factoriser en temps raisonnable, même sur un supercalculateur. Toute la sécurité d'HTTPS, des cartes bancaires, des signatures numériques repose là-dessus.

L'essentiel du chapitre

Nombre premier

p \geq 2, ses seuls diviseurs sont 1 et p. L'ensemble des nombres premiers est infini (Euclide).

Test

Pour tester si n est premier, essayer les diviseurs jusqu'à \sqrt n. Au-delà, Fermat ou Miller-Rabin.

Décomposition

Tout n\geq 2 s'écrit uniquement p_1^{\alpha_1}\cdots p_k^{\alpha_k}. Donne le nombre de diviseurs, le PGCD, le PPCM.

Fermat

Pour p premier : a^p \equiv a \pmod p. Si a \wedge p = 1 : a^{p-1} \equiv 1 \pmod p.

TP Python

Test exact par divisions jusqu'à \sqrt n. Décomposition en facteurs premiers. Test probabiliste de Fermat avec pow(a, n-1, n).

RSA

Clé publique (n, e), privée d avec ed \equiv 1 \pmod{\varphi(n)}. Chiffrer c = m^e \bmod n, déchiffrer m = c^d \bmod n.
